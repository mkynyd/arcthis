下载 Arcthis。

Arcthis 用固定版本的 Rust 工具链从源码编译,依赖版本也已锁定(--locked),每次编译结果一致,并在 macOS 和 Linux 上都经过自动化测试。

如实说明:v0.5.0 还没有 crates.io 安装包,也没有编译好的可执行文件。下面的命令就是目前完整的安装方法,一步不少。

  1. 安装 Rust 与系统依赖

    仓库已用 rust-toolchain.toml 固定 Rust 1.98.0,进入项目目录后 rustup 会自动切换。RAR 支持依赖 libarchive,因此编译前需要安装它和相关的解压库。

    macOS — Homebrew 
    brew install libarchive libb2 bzip2 lz4 xz zstd
    Debian / Ubuntu — apt 
    sudo apt install libarchive-dev libb2-dev libbz2-dev \
  liblz4-dev liblzma-dev libxml2-dev libzstd-dev zlib1g-dev

  2. 下载源码并编译

    编译完成后,程序位于 target/release/arcthis。默认编译同时包含命令行工具、库和 MCP 功能,与后续 Homebrew、npm、pnpm 安装的命令保持一致。

    build — sh 
    git clone https://github.com/mkynyd/arcthis.git
cd arcthis
cargo build --release --locked
./target/release/arcthis --help

  3. 把 arcthis 加入 PATH(可选)

    装好后 arcthis 会加入 PATH,在任何目录都能直接运行。

    install — sh 
    cargo install --path . --locked
arcthis --version
# arcthis 0.5.0

  4. 启动 MCP

    本地 MCP 服务已经包含在默认构建中。除非你同时授权输出目录,否则修改类工具不会出现。

    mcp — sh 
    cargo build --release --locked
arcthis mcp --allow-root ./archives --allow-output-root ./outputs
