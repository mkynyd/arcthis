Download Arcthis.

Arcthis is compiled from source with a fixed Rust version. Dependency versions are locked (--locked) so the build is the same every time, and it's covered by automated tests on macOS and Linux.

Honest status: v0.5.0 has no crates.io package and no ready-made binary yet. The commands below are the complete, current way to install it — nothing is left out.

  1. Install Rust and system dependencies

    The repository fixes Rust 1.98.0 via rust-toolchain.toml — rustup switches to it automatically inside the project directory. RAR support needs libarchive, so install it and its decompression libraries before building.

    macOS — Homebrew 
    brew install libarchive libb2 bzip2 lz4 xz zstd
    Debian / Ubuntu — apt 
    sudo apt install libarchive-dev libb2-dev libbz2-dev \
  liblz4-dev liblzma-dev libxml2-dev libzstd-dev zlib1g-dev

  2. Download the source and build

    The build produces the CLI at target/release/arcthis. A default build includes the CLI and library only — no MCP.

    build — sh 
    git clone https://github.com/mkynyd/arcthis.git
cd arcthis
cargo build --release --locked
./target/release/arcthis --help

  3. Put arcthis on your PATH (optional)

    Once installed, arcthis is on your PATH, so you can run it from any directory.

    install — sh 
    cargo install --path . --locked
arcthis --version
# arcthis 0.5.0

  4. Optional: MCP support

    The local MCP server has to be enabled at build time. Write tools stay hidden unless you also grant an output directory.

    mcp — sh 
    cargo build --release --locked --features mcp
arcthis mcp --allow-root ./archives --allow-output-root ./outputs
