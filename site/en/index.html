01 — Quickstart

From clone to first inspect in three commands.

v0.5 currently ships as source only — no crates.io package and no ready-made binaries yet. RAR support needs libarchive; see Download for platform dependencies.

install — zsh
$ git clone https://github.com/mkynyd/arcthis.git $ cd arcthis $ cargo build --release --locked $ ./target/release/arcthis --version arcthis 0.5.0
02 — Signature moves

One command style. Every format. Nothing extracted unless you ask.

The same arcthis <command> <archive> [entry] shape works with ZIP, 7z, RAR, TAR and single-file compression formats. Every session below is real output from Arcthis 0.5.0.

move / 01

Find files without decompressing

find matches paths against the archive's file list using wildcards. File contents are never read, so finding files stays fast even on multi-gigabyte archives.

find
$ arcthis find dataset.zip --glob '**/*.csv' dataset/train/labels.csv dataset/train/data.csv
move / 02

Search contents in place

grep scans text files directly inside the archive, with caps on file size, lines, matches and binary files. Nothing is written to disk while you search.

grep
$ arcthis grep dataset.zip TODO --glob '**/*.md' dataset/docs/notes.md:1:TODO: fill in preprocessing notes dataset/README.md:3:Sample training bundle. TODO: document the schema.
move / 03

Verify without extracting

hash computes a file's SHA-256 or SHA-512 checksum; verify reads the archive start to finish once, checking its structure and every readable file.

hash · verify
$ arcthis hash dataset.zip dataset/train/data.csv 3307d48518fd5bc59980caee9f4833a1aef4a3ae7f16ef4102a132b719d947c2 dataset/train/data.csv $ arcthis verify dataset.zip verified 7 entries (200124 bytes)
move / 04

Rehearse before you write

pack, extract and convert all accept --dry-run to preview the full plan before anything is written. Real writes go to a temporary location first and are saved as final only after verification passes.

pack --dry-run
$ arcthis pack ./dataset --output dataset.tar.zst --dry-run dry-run pack plan source: ~/demo/dataset destination: dataset.tar.zst format: tar_zstd entries: 7 estimated bytes: 200124 collision: false will skip: false delete source after success: false
move / 05

Archives inside archives

Repeat --within to step into archives nested inside archives — up to 8 levels deep, entirely in memory, with no temporary files left on disk.

tree --within
$ arcthis tree backup.zip --within project.tar.gz backup.zip::project.tar.gz └── dataset ├── README.md ├── docs │ └── notes.md └── train ├── data.csv └── labels.csv
move / 06

Structured by default, for agents

Add --json to any query command for versioned JSON: fields stay stable, errors carry fixed codes on stderr, and exit codes are predictable.

stat --json
$ arcthis stat dataset.zip dataset/train/labels.csv --json {"schema_version":"1","archive":{"path":"dataset.zip","path_lossy":false,"format":"zip"},"entry":{"archive_index":5,"path":"dataset/train/labels.csv","path_encoding":"utf8","kind":"file","size":28,"compressed_size":28,"modified_time":"2026-08-30T01:05:30","encrypted":false,"executable":false,"symlink_target":null,"crc32":"9e6ad3e5","mime_guess":"text/csv"}}
03 — Formats

Twelve formats, one way to work.

04 — Agent interface

JSON is the contract. Stable fields, versioned schema.

  • Real structured output. Every successful response is one JSON document with schema_version: "1". Field names and types are a public, versioned interface.
  • Clean output separation. Results go to stdout; diagnostics, warnings and errors go to stderr. read prints raw file contents and rejects --json.
  • Predictable failures. Errors come as JSON with fixed codes, each mapped to a deterministic exit code.
  • Honest costs. inspect reports capabilities like random_access and solid, so an agent can reason about what an operation will cost.

05 — Safety model

Safe before convenient, by default.

An archive from an untrusted source can be malicious. Every write is careful, verified and all-or-nothing — shortcuts exist, but you always have to ask for them explicitly.

paths

One path safety check

Extraction rejects .., absolute paths, Windows drive/UNC prefixes, NUL bytes, and links that could escape the destination.

writes

Temporary first, saved when done

Output is written to a temporary location next to the destination and saved only after every file succeeds. A failure never leaves a half-finished result that looks complete.

collisions

Refuse by default

Existing destinations are refused unless you pass exactly one explicit policy: --overwrite, --skip-existing or --rename.

deletion

Source deleted last

--delete-source runs only after the new files are written, verified and saved. Any error, interruption or failed check keeps the source.

06 — MCP

The same commands, straight into your AI agent.

  • An optional MCP server. Enabled at build time, pinned to protocol revision 2025-06-18, with bounded resource use and nothing but data on stdout.
  • Nine read-only tools for inspect, list, tree, stat, read, find, grep, hash and verify — available once you explicitly grant a directory with --allow-root.
  • Six write tools (plan + execute for extract/pack/convert) appear only after you grant an output directory with --allow-output-root.
  • Outdated plans are refused. If the source or destination changes after a plan is made, the plan's SHA-256 fingerprint no longer matches and it won't run.
mcp — zsh
$ cargo build --release --locked --features mcp $ arcthis mcp --allow-root ./archives # read-only tools only $ arcthis mcp --allow-root ./archives --allow-output-root ./outputs # plan/execute mutation tools become visible
